# Portfolio refonte

Version statique refondue du portfolio de Sydol Thériaul ADOMADE.

## Structure

- `index.html` : page principale refondue.
- `assets/css/styles.css` : styles dédiés à la nouvelle version.
- `assets/js/main.js` : menu mobile, année automatique et navigation active.
- `assets/imgs/` : images réutilisées depuis le portfolio existant.
- `assets/docs/` : CV, rapports PDF et mini-projet OpenLayers.

Le site peut être ouvert directement depuis `index.html`.
